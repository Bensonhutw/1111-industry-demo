1111 製造業專區 Demo（多頁版）

使用方式
1. 解壓縮後，在瀏覽器開啟 index.html；頁面資料不需伺服器或 API。
2. 上傳 GitHub 時，將所有 HTML 與 assets 資料夾一起上傳至 1111-industry-demo 儲存庫最外層。
3. 保留原本 GitHub Pages：main 分支 / (root)。
4. 不要直接上傳 ZIP；不要把整個 industry-demo 資料夾當成另一層網站根目錄。

頁面
index.html       首頁
jobs.html        找工作：篩選、排序、分頁與網址條件
job.html         舊網址相容入口：轉往 1111 主站

限制與資料
企業、職缺、文章與產業趨勢為示範資料。職缺卡片的薪資也是示範。
職涯頁的薪資、職務介紹、相關證照與職能，整理自 1111 薪資公秤與職務大辭典，擷取日期為2026-10-03。
職涯內容已內建於 data.js，可直接在頁面閱讀；這是來源資料快照，不會隨外部來源自動更新。
薪資各職務的統計期間依來源主文顯示，相關證照不表示每項都是必備。
示範職缺不能投遞履歷；卡片連到 1111 對應職類／產業搜尋，正式上稿可填入真實 officialUrl 直接連到主站詳細頁。
薪資公秤、職涯大師與官方 LOGO 使用既有 1111 網址，需要網路連線。
相關證照與職能已呈現來源內容；課程報名與正式資格資訊仍依各服務公告。
洽詢表單只模擬成功，資料不會傳送或保存。
所有頁面均需保留 assets 資料夾；首頁推薦工作使用共用 data.js，配圖在 assets/images。
無登入、資料庫或正式 API；不包含帳號或金鑰。

驗證
已檢查 JavaScript 語法、各頁資料呈現、跨頁連結、條件合併、搜尋與空結果、無效ID、分頁與返回參數。
此環境未完成真實瀏覽器視覺驗證，上傳後請確認桌機與手機版面。

好公司與上市櫃排行
搜尋採用製造業對照表列出的 102 項 1111 產業小類，按上市櫃產業群組排列；地區保留官方縣市及行政區。
搜尋主網 GET 參數 t0/c0/ks/page；全域及各群組選項僅傳入對照表列出的產業小類碼。
年薪來源：同一對照表「上市櫃」工作表，114 年（2025），原始仟元除以 10 呈現萬元／年；漲幅原表比例乘 100。
依「製造業」工作表的 25 個上市櫃產業分類納入 1,548 家公司，包括表列半導體、電子等分類。
原表僅提供上市櫃產業分類，沒有逐家公司對應的 1111 產業小類或公司編號，尚未逐家公司認定製造資格。
六大公開產業依原表上市櫃家數：電子零組件業 200、半導體業 191、生技醫療業 141、光電業 112、電腦及週邊設備業 105、電機機械 93。
總榜及各產業公開前十名，依平均年薪降冪；產業平均直接取原表同業公司資訊，上市／上櫃分別呈現，不自行計算。
assets/company-data.js 存公開排行與分類；assets/salary-full.js 存完整 1,548 筆預覽資料。
corpIds 可用股票代碼填入真實 1111 公司編號；目前未填入，回主網以公司名稱搜尋。
salary.html 為獨立完整排行，每頁 25 筆；Demo 尚未介接會員驗證，可使用「預覽會員排行（Demo）」查看。
正式會員功能需服務端驗證；靜態 JS 不具存取限制。
好公司推薦主題保留上市櫃、外商、工業區、智慧製造、培訓友善，各八張卡；標籤均為 Demo。
