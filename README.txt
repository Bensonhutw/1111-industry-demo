1111 製造業專區 Demo（多頁版）

使用方式
1. 解壓縮後，在瀏覽器開啟 index.html；頁面資料不需伺服器或 API。
2. 上傳 GitHub 時，將所有 HTML 與 assets 資料夾一起上傳至 1111-industry-demo 儲存庫最外層。
3. 保留原本 GitHub Pages：main 分支 / (root)。
4. 不要直接上傳 ZIP；不要把整個 industry-demo 資料夾當成另一層網站根目錄。

頁面
index.html       首頁
jobs.html        找工作：篩選、排序、分頁與網址條件
job.html         舊網址相容入口：轉往 1111 主站
companies.html   企業列表
company.html     舊網址相容入口：轉往 1111 主站
trends.html      月度產業情報、歷史指數與職務需求
articles.html    企業報導、人物專訪與工作甘苦談列表
article.html     文章內頁與相關職缺
career.html      職務三層點選、薪資比較、職務介紹、證照與能力內容
business.html    廣告合作方案與模擬洽詢
assets/style.css 共用視覺
assets/data.js   示範資料與 1111 職涯來源摘錄
assets/app.js    各頁搜尋與導流

限制與資料
企業、職缺、文章與產業趨勢為示範資料。職缺卡片的薪資也是示範。
職涯頁的薪資、職務介紹、相關證照與職能，整理自 1111 薪資公秤與職務大辭典，擷取日期為2026-10-03。
職涯內容已內建於 data.js，可直接在頁面閱讀；這是來源資料快照，不會隨外部來源自動更新。
薪資各職務的統計期間依來源主文顯示，相關證照不表示每項都是必備。
示範職缺不能投遞履歷；卡片連到 1111 對應職類／產業搜尋，正式上稿可填入真實 officialUrl 直接連到主站詳細頁。
薪資公秤、職涯大師與官方 LOGO 使用既有 1111 網址，需要網路連線。
相關證照與職能已呈現來源內容；課程報名與正式資格資訊仍依各服務公告。
洽詢表單只模擬成功，資料不會傳送或保存。
所有頁面均需保留 assets 資料夾；首頁推薦工作使用共用 data.js，配圖在 assets/images。
無登入、資料庫或正式 API；不包含帳號或金鑰。

驗證
已檢查 JavaScript 語法、各頁資料呈現、跨頁連結、條件合併、搜尋與空結果、無效ID、分頁與返回參數。
此環境未完成真實瀏覽器視覺驗證，上傳後請確認桌機與手機版面。
